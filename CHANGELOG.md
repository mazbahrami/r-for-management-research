# Changelog

## 0.2.0 — 2026-07-28

- Replaced branch-based publishing with native GitHub Pages Actions.
- Updated the workflow to Node.js 24-compatible `actions/checkout@v6`.
- Corrected the Quarto project working directory with
  `project.execute-dir: project`.
- Added an explicit render list and excluded the student report template from
  automatic execution while keeping it downloadable.
- Corrected mediation examples so mediator and outcome models use identical
  complete cases.
- Added `downlit` and `xml2` to remove code-linking dependency warnings.
- Regenerated the hotel dataset with all documented loyalty categories,
  including the `None` reference group.
- Revalidated data schemas, links, lesson/script pairs, and teaching patterns.
- Rewrote deployment instructions around a clean GitHub Desktop workflow.

- Added five synthetic and documented teaching datasets.

- Added editable Quarto slide decks and instructor materials.
- Added GitHub Pages automation and personal-website integration files.
