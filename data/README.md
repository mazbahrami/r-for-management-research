# Teaching datasets

The CSV files in this folder are synthetic teaching data generated specifically
for *Learning R for Management Research*.

They do not contain real people, firms, hotels, customers, or Luiss University
data.

## Files

- `employee_survey.csv`
- `training_experiment.csv`
- `marketing_mix.csv`
- `hotel_upgrades.csv`
- `employee_replication.csv`
- `data_dictionary.csv`

The generation code is in `../data-raw/`.
