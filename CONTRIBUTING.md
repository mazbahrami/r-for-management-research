# Contributing

Corrections and teaching improvements are welcome through GitHub issues or pull
requests.

Please:

- keep explanations suitable for beginners;
- connect each addition to a clear research question;
- use reproducible, commented R code;
- preserve the distinction between association and causation;
- do not add datasets without explicit provenance and redistribution rights;
- label simulated data clearly;
- update exercises and solutions together when changing a lesson.

By contributing teaching text, you agree that it may be distributed under CC BY
4.0. Code contributions are distributed under the MIT License.
