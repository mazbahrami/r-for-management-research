# Course alignment: Research Project Design

This teaching package is designed for beginner R/RStudio workshops supporting
**Research Project Design** at Luiss Guido Carli University. It is not an
official Luiss publication and should be adapted to the final teaching contract,
calendar, and instructor coordination.

## Suggested five-lab sequence

| Lab | Course need | Repository material | Core output |
|---|---|---|---|
| 1 | Introduction to R and RStudio | Modules 1–2 | Cleaned data and descriptive table |
| 2 | Descriptives, correlations, t-tests | Module 3 | Group comparison with interpretation |
| 3 | Reliability, EFA, chi-square | Modules 4–5 | Measurement assessment and association test |
| 4 | Linear regression and diagnostics | Module 6 | Marketing-mix model and diagnostics |
| 5 | Moderation, mediation, replication | Modules 7 and 9 | Interaction plot, indirect effect, replication table |

**Optional extension:** Module 8 covers logistic regression using the hotel
upgrade case.

## Boundaries

The material intentionally omits advanced programming, loops, package
development, causal inference, multilevel models, structural equation modelling,
and machine learning. The emphasis is correct beginner workflow and responsible
interpretation.
