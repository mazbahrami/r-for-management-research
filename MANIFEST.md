# Repository manifest

## Student-facing website

- `index.qmd` — landing page and learning pathway
- `getting-started.qmd` — installation and first use
- `course-map.qmd` — alignment with the course
- `modules/` — nine complete lessons
- `exercises/` — eight practice worksheets
- `solutions/` — concise worked solutions
- `datasets.qmd` and `data/README.md` — data documentation
- `resources.qmd` — selected further learning

## RStudio materials

- `r-for-management-research.Rproj`
- `code/` — one complete script per module
- `data/` — five ready-to-use CSV datasets and dictionary
- `R/install_packages.R` — package installer
- `R/check_setup.R` — environment check
- `templates/research-report.qmd` — student report template

## Instructor materials

- `instructor/course-alignment.md`
- `instructor/lesson-plans.md`
- `instructor/teaching-notes.md`
- `instructor/assessment-bank.md`

- `data-raw/` — R scripts regenerating simulated datasets
- `references/` — benchmark and dataset-selection rationale
- `DESCRIPTION` — package requirements
- `CITATION.cff` — citation metadata
- content and code licences
